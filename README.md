# The Foundations of Graph Signal Processing

Welcome to the official repository for "The Foundations of Graph Signal Processing". This repository contains Python code related to the course materials, providing practical examples and exercises to enhance your understanding of graph signal processing.

## Course Website

For more information about the course, visit the official course website at [mohammadraziei.github.io/GSPbook/](https://mohammadraziei.github.io/GSPbook/).

## About the Authors

- **Arash Amini**: A professor in signal processing at Sharif University of Technology. For more information, visit [Arash Amini's Homepage](https://sharif.ir/~aamini/).
- **Mohammad Raziei**: An expert in signal processing, contributing significantly to the field. For more information, visit [Mohammad Raziei's Homepage](https://mohammadraziei.github.io).
